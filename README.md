# Piano | Comparativo

Projeto Integrador da disciplina **Desenvolvimento Front-End para Web** (UNIPÊ), feito por Adrian Asaf.

O site é um catálogo comparativo de pianos. Ele apresenta os principais tipos de piano (de cauda, vertical, digital e híbrido), explica como cada um produz o som e para quem é indicado, e mostra faixas de preço de referência.
O objetivo é ajudar quem está começando a tocar a entender as diferenças entre os modelos antes de escolher o seu.

## Estrutura

```
index.html
css/      estilos (reset.css e style.css)
js/       scripts
assets/   imagens, vídeo e áudio
```
